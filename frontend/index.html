About TripCraft

An individual BCA 5th Semester Web Application Development Project designed to make sustainable, offbeat exploration accessible and budget-conscious.

Project Purpose & Motivation

Mainstream Indian tourism is heavily concentrated in crowded commercial hubs, often straining local ecosystems while leaving travelers with generic experiences. TripCraft was conceived to champion 9 hidden gems across India—from the secluded beaches of Gokarna to the high-altitude serenity of Chopta and the Apatani heritage of Ziro Valley.

The goal of this project is to blend travel storytelling with practical engineering: offering transparent destination-specific cost algorithms, authentic regional transit data, and day-by-day itineraries tailored to different traveler preferences.

Promotes Sustainable Tourism Encourages travel to local homestays and indigenous cultural centers.
Transparent & Realistic Costing No fabricated numbers; realistic regional lodging, food, and transit estimates.
Clean & Viva-Ready Architecture Pure HTML5, CSS3, Vanilla JS, and lightweight Python Flask backend.

Technical Stack & Architecture

  • Frontend
    HTML5 & Semantic Structure Accessible forms, modular sections, and semantic markup.
  • Styling
    CSS3 & Responsive Design Flexbox, CSS Grid, custom properties, and smooth animations.
  • Interaction
    Vanilla JavaScript (ES6+) DOM manipulation, client validation, asynchronous fetch API, and accordion UI.
  • Backend
    Python Flask REST API Lightweight routing, request validation, and destination cost computation.
